# UI references, wave f2: Among Us, Goose Goose Duck, Lethal Company, Content Warning, R.E.P.O.

Collected 2026-10-02. Nothing was downloaded; every URL below is text only. I cannot see images: the "shows"
column is what the page, caption or section says, never what the picture looks like.

How to read it:
- **Confidence**: high = the page or caption names that screen; medium = strongly implied; low = a guess.
- **Steam store shots** come from the store API (`data.screenshots[].path_full`). The API carries **no captions**,
  so which shots contain UI is unknown until someone looks; they are listed as `other / low`.
- All Steam hashes were length-checked (40 hex). The WebFetch summarizer once garbled an R.E.P.O. hash; the
  verbatim re-fetch is what is listed.
- Source health this wave: Fandom wikis returned HTTP 402, BreezeWiki a bot check, Steam Community guides HTTP 429,
  GameSpot / Dot Esports / Attack of the Fanboy HTTP 403. Wiki and guide pages below are search-result URLs only.
- Game UI Database has **no entry** for any of these five; it does have **Among Us VR** (first-person 3D Among Us).
