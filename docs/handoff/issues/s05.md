## Goal
Build the Esc menu in the Toy style, exactly as the UI track drew it. The menu exists (#169, `esc_menu.gd`, `esc_menu_state.gd`; the Voice tab #220, `voice_panel.gd`): this issue reworks its look and adds the Role, Guide, Character and Settings pages.

## Build
The scene tree, node for node, is in prime-game-ui [`docs/handoff/s05-esc-menu.md`](https://github.com/xperiaroco2/prime-game-ui/blob/ui-0.2.0/docs/handoff/s05-esc-menu.md) at the tag `ui-0.2.0`. The states are drawn on the review page https://claude.ai/artifact/SCREENS_URL (screen s5; uk and en, default and large text).

- CanvasLayer 4: `Dim` (ToyBackdropDeep) and `Menu`, a raised 1600×880 ToyPanelMenu: `Tabs` (288 px ToyTab buttons) and `Page` (the title row, then one page per tab).
- CanvasLayer 5: the confirm dialog (`ConfirmDim`, `Confirm`: ToyPanelDialog, raised).
- Pages: Lobby (preset cards, a 784 px settings column, and the side column: the code row, the scrolling players list and Ready), Character, Game, Role, Guide (chips and the shared how-to card of ISSUE_S8), Settings (sub-page chips and a scrolling list of setting rows; one scene that the main menu instances too).
- States: `lobby-host`, `lobby-guest`, `lobby-no-code`, `character`, `character-round`, `game-host`, `game-guest`, `game-confirm`, `role-engineer`, `role-dissident`, `guide`, `settings-sound`, `settings-controls`, `settings-display`, `settings-access`, `settings-language`, `tutorial-game`.

Rules:
- Theme type variations from the `ui-0.2.0` pack only (#288). No `add_theme_*_override` and no `theme_override_*` (`theme_test.gd`): gaps come from the spacing variations (`ToyColumn…`, `ToyRow…`, `ToyGridList`, `ToyGridSwatch`; `ToyScroll` for a list's gap to its bar), and a gap the scale lacks is the empty `Control` spacer the handoff gives.
- Raised panels and buttons through `ToyRaised` (placement, size and visibility on the wrapper), presses through `ToyPress`, toggles through `ToyToggle` (#289).
- Every player-facing text is a deck key through `tr()` (`tr_n()` for a plural). A key with placeholders is set from code with `auto_translate_mode = DISABLED` and rebuilt on `NOTIFICATION_TRANSLATION_CHANGED` (#208). Data texts (names, the code, setting values, device names, key labels) are set from code with `auto_translate_mode = DISABLED`.
- Sizes and offsets are px at the 1920×1080 base (#287). A size from a variation's size constants is read with `get_theme_constant()` into `custom_minimum_size`, as the node lines give it.
- Icons are the pack's white SVGs, tinted as each node line says, imported at the `svg/scale` the handoff's notes give.
- Sliders take their grabber textures from the theme and draw their focus ring in code; every ScrollContainer sets `get_v_scroll_bar().theme_type_variation = &"ToyScrollBar"` (#289).

## Behaviour
- Over the running game, no pause. Esc opens and closes it; the mouse is free while it is open and captured on close. While it is open the own character takes no gameplay input and voice keeps working (ISSUE_INPUT).
- Tabs: one ButtonGroup; the page title is the selected tab's name. Default tab: Lobby in the lobby, Game in a round and in the tutorial; the last tab is kept for the session. Role is hidden in the lobby; the tutorial shows only Game, Guide and Settings. Focus starts on the selected tab; on Game, Resume takes it.
- Lobby, the host: preset cards (Standard, Quick, No knives) in one ButtonGroup; a card applies its values; any other change deselects every card, and players then read `preset.custom`. Save (not in the group) stores one own preset, which appears as a card before Save. The rows: the lobby name (#214), match duration, packages, dissidents and knives (the base mode's settings, steppers within their bounds), tasks (one toggle chip per task type, selected = allowed: `banned_task_types`), and a step count per complex task type (#256), hidden while that task is banned. The host's edits apply live for everyone.
- Steppers: Less and More are reached by focus (`ui_left`, `ui_right`) and step with `ui_accept`; at a bound the other arrow takes focus before this one is disabled, so focus never rests on an unplugged arrow.
- Lobby, a player (and everyone in a round): values without steppers, tasks as static chips (allowed ToyChipLight, banned ToyChipLineOnLight), the host-only line with the host's name by a lock, `esc.lobby.preset` with the applied preset; the lobby name is a read-only field.
- Side column: the room code (a keycap) with Copy, to the host who hosted with a code and each player who joined with it; Copy calls `DisplayServer.clipboard_set(code)` and reads `esc.lobby.copied` for 1.5 s. Hidden for Direct. `lobby-no-code`: `esc.lobby.code_gone` in its place when the code service closed or was never reachable. The players list scrolls between the code row and Ready (`follow_focus`), so 10 players never make the menu taller; rows as on the lobby HUD, names cut with an ellipsis, ready marks hidden in a round. Ready: ToyButtonPrimary, pressed with the check icon while ready; hidden in a round.
- Character: changes apply live in the lobby; in a round the tab is locked (the lock line in the title row, the name read-only, the swatches take no input). The own character in a SubViewport; the name field; ten body colour swatches (TextureButton toggles in one ButtonGroup, 26×26, the disc tinted with the body colour, content data, #73, #255; `focus_mode` NONE and `mouse_filter` IGNORE in a round). The Hat row stays hidden until hats exist.
- Game: Resume closes the menu. Leave: the host's is coral and opens the confirm dialog; a player's leaves at once; in the tutorial it reads `esc.game.leave_tutorial` and goes back to the main menu. Quit: the host's opens the same dialog titled `esc.game.quit_confirm`; a player's, and the tutorial's, quits at once.
- Confirm dialog: `ConfirmDim` stops the mouse; `focus_behavior_recursive = FOCUS_BEHAVIOR_DISABLED` on Menu while it is open, restored on close; Cancel takes focus; `ui_cancel` = Cancel, consumed with `set_input_as_handled()`, so Esc closes only the dialog. Confirm ends the session for every player and returns to the main menu (Quit: quits the game).
- Role (in a round only): the own role and its goal; a dissident also sees the team (the count and a two-column list in join order that scrolls in a 250 px view; hidden with no teammates). It reads only the own role and `Teammates` (#175).
- Guide: chips in a scrolling column, one ButtonGroup: the basics (moving, voice, downed: cards built from the tutorial's keys) and one per task type; a chip shows its how-to card (#254).
- Settings: sub-pages Sound and voice (the default), Controls, Display, Accessibility, Language; the rows scroll (`follow_focus`). Saved per player.
  - Sound and voice: Mic (dropdown: `settings.mic.default`, then the device names, cut with an ellipsis; a pick opens the device under the existing opening mark), the talk mode (dropdown: voice activation, push to talk, off), the threshold (voice activation only) with the live meter, noise suppression (two chips), four volume sliders (Master, voice, effects, music buses, 0 to 100 %). Without the voice add-on the voice rows give way to `settings.voice_unavailable`.
  - Controls: 16 rows, each a ToyKeyButton with the bound key's label. A click or `ui_accept` starts capture: `toggle_mode = true` and `set_pressed_no_signal(true)` with `settings.controls.press_key`, both restored after. Capture runs in `_input` and consumes every event; the next key or mouse button binds, except the release of the click that started it; Esc cancels and is consumed (the menu stays open); the arrows and `ui_accept` do not move or press focus while capturing. A row whose key clashes with another action of the same phase shows ToyChipAlert `settings.controls.same_key` (give_up and ready share F legally). Reset restores the defaults; Esc is fixed (#211, ISSUE_INPUT).
  - Display: the window mode (two chips). Accessibility: large text (swaps GameUi's theme to `game_theme_large.tres` live) and reduced motion (default from `DisplayServer.accessibility_should_reduce_animation()`; on: the connecting spinner at half speed, the pre game, post game and End fades as cuts, the press instant) (#289). Language: two chips, each language named in itself, applied at once (#208).
- Dropdown lists are PopupMenus in Godot's default theme until a Toy PopupMenu comes (a prime-game-ui follow-up); LineEdits set `context_menu_enabled = false`.
