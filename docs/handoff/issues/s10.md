## Goal
Build the post game screen in the Toy style, exactly as the UI track drew it: the black outro of about 3 s with the winning team and the own result, then everyone back in the lobby. The end screen exists (#142, `end_screen.gd`): this issue reworks its look.

## Build
The scene tree, node for node, is in prime-game-ui [`docs/handoff/s10-post-game.md`](https://github.com/xperiaroco2/prime-game-ui/blob/ui-0.2.0/docs/handoff/s10-post-game.md) at the tag `ui-0.2.0`. The states are drawn on the review page https://claude.ai/artifact/SCREENS_URL (screen s10; uk and en, default and large text).

- On the black-screen layer (CanvasLayer 6): `Night` (ToyBackdropNight, opaque) and `V`, a centred 1440 px ToyColumnThirtyTwo: `end.title`, the winner on a ToyTitlePlate (a Label raised on ToyBaseTitle), the own result and the reason, a spacer, then the countdown.
- States: `win`, `lose`.

Rules:
- Theme type variations from the `ui-0.2.0` pack only (#288). No `add_theme_*_override` and no `theme_override_*` (`theme_test.gd`): gaps come from the spacing variations (`ToyColumn…`), and a gap the scale lacks is the empty `Control` spacer the handoff gives.
- The title plate through `ToyRaised` (placement, size and visibility on the wrapper, #289).
- Every player-facing text is a deck key through `tr()`. A key with placeholders is set from code with `auto_translate_mode = DISABLED` and rebuilt on `NOTIFICATION_TRANSLATION_CHANGED` (#208).
- Sizes and offsets are px at the 1920×1080 base (#287).

## Behaviour
- When the End phase starts, Night fades in over 0.4 s (a cut under reduced motion). One sound plays for both outcomes; no voice is routed (#213). No input.
- Winner: `end.won_engineers` or `end.won_dissidents`. Result: `end.your_team_won` or `end.your_team_lost`, from the own team.
- Reason, from the host's reason id (#208): `end.reason.all_tasks` with the round's time (m:ss) or `end.reason.time_up`. An unknown reason hides the line.
- `end.back_to_lobby` counts 3, 2, 1, once a second; at 0 everyone is back in the lobby (#212). No host button.
- Roles are not revealed. Nobody hears anybody and no text says so.

## Texts
`end.title`, `end.won_engineers`, `end.won_dissidents`, `end.your_team_won`, `end.your_team_lost`, `end.reason.all_tasks`, `end.reason.time_up`, `end.back_to_lobby`. Every key has en and uk in prime-game-ui `copy/strings.csv`.
