## Goal
Build the main menu in the Toy style, exactly as the UI track drew it. The menu and the join exist (#142, `main_menu.gd`; join with a code, #373 in PR #430): this issue reworks their look, and adds the name row and the Settings panel (#301).

## Build
The scene tree, node for node, is in prime-game-ui [`docs/handoff/s02-main-menu.md`](https://github.com/xperiaroco2/prime-game-ui/blob/ui-0.2.0/docs/handoff/s02-main-menu.md) at the tag `ui-0.2.0`. The states are drawn on the review page https://claude.ai/artifact/SCREENS_URL (screen s2; uk and en, default and large text).

- Its own scene, under none of the in-game CanvasLayers. The live lobby stays behind `Backdrop` (ToyBackdrop) with an idle camera.
- `Column`: the logo (the working title, a data text), the name row, and `Body`: the 592 px `Items` column of ToyMenuItem buttons with the open panel to their right.
- `CodePanel` and `DirectPanel`: raised ToyPanelMenu, 784 px, no title (the pressed item names the open panel).
- `SettingsPanel`: a raised 960×888 root holding the Esc menu's Settings scene. `Version`: muted, bottom right.
- States: `main`, `code`, `code-ready`, `direct`, `settings`.

Rules:
- Theme type variations from the `ui-0.2.0` pack only (#288). No `add_theme_*_override` and no `theme_override_*` (`theme_test.gd`): gaps come from the spacing variations (`ToyColumn…`, `ToyRow…`, `ToyGridList`, `ToyGridSwatch`; `ToyScroll` for a list's gap to its bar), and a gap the scale lacks is the empty `Control` spacer the handoff gives.
- Raised panels and buttons through `ToyRaised` (placement, size and visibility on the wrapper), presses through `ToyPress`, toggles through `ToyToggle` (#289).
- Every player-facing text is a deck key through `tr()` (`tr_n()` for a plural). A key with placeholders is set from code with `auto_translate_mode = DISABLED` and rebuilt on `NOTIFICATION_TRANSLATION_CHANGED` (#208). Data texts (names, codes, numbers) are set from code with `auto_translate_mode = DISABLED`.
- Sizes and offsets are px at the 1920×1080 base (#287). A size from a variation's size constants is read with `get_theme_constant()` into `custom_minimum_size`, as the node lines give it.
- Icons are the pack's white SVGs, tinted as each node line says, imported at the `svg/scale` the handoff's notes give.

## Behaviour
- Items: Host, Join, Join by address, Tutorial, Settings, Quit. Up and down move the focus; the focused, hovered or pressed item shows its pointer icon (ToyMenuItem's `icon_*_color`). Focus starts on Host.
- Host hosts a game with a code and goes straight to the lobby (s4); a failure shows s3 `host-failed`. Tutorial loads lesson 1 (s1). Quit quits at once. No server browser.
- Join, Join by address and Settings are one ButtonGroup with `allow_unpress`. Pressing one opens its panel (it stays pressed, with ToyMenuItem's own pressed look); pressing it again, Back or Esc (`ui_cancel`) closes it.
- Name: the player's name, kept between sessions (`user://`), never empty (the last name used, else the system user name), `max_length` 16. Every LineEdit sets `context_menu_enabled = false` (no Toy PopupMenu look yet).
- Code panel: the field is focused and empty on open; `max_length` 6; upper-cases as typed, drops spaces and dashes on paste, takes only the 31-letter code alphabet (no 0, O, 1, I, L); keeps what was typed after a failure. Join stays disabled (unplugged) until the field holds 6 valid characters; Enter = Join when enabled; it joins by the code (s3).
- Direct panel: Address is focused on open and takes host or host:port, host names included (`JoinTarget`); the port line shows the default. Join is disabled while Address is empty and joins over ENet (s3, no code row). Host hosts directly on the typed port, else the default, and opens the lobby with no code row. No address is shown anywhere else.
- Settings panel: the Esc menu's Settings scene, one scene for both menus (ISSUE_S5), opened on Sound and voice. The mic, the mode, the threshold with its live meter, noise suppression and the volumes work without a session, and nothing is sent (#301). Focus goes to Sound on open; Settings again or Esc closes it and gives the focus back to the Settings item.
- Version: `menu.version` with `application/config/version`.
