## Goal
Build the round HUD in the Toy style, exactly as the UI track drew it. The HUD exists (#144, `hud.gd`, `hud_text.gd`): this issue reworks its look to the drawn layout. The tutorial (s1), pre game (s6) and downed (s9) screens reuse these nodes, so they are built once, here.

## Build
The scene tree, node for node, is in prime-game-ui [`docs/handoff/s07-hud.md`](https://github.com/xperiaroco2/prime-game-ui/blob/ui-0.2.0/docs/handoff/s07-hud.md) at the tag `ui-0.2.0`. The states are drawn on the review page https://claude.ai/artifact/SCREENS_URL (screen s7; uk and en, default and large text).

- `Plates` (CanvasLayer 1): the name plate layer, one ToyNamePlate per visible player.
- `Hud` (CanvasLayer 2), edges 40 px in: `Timer` (top centre), `Role` (a chip, top left), `Cross` and `Aim` (centre), `Vitals` (bottom left: health, stamina, mic), `Slots` (bottom right: hand and belt), and `Raising` (see below).
- States: `empty`, `pack`, `tired`, `hurt`, `mate`, `raising`.

Rules:
- Theme type variations from the `ui-0.2.0` pack only (#288). No `add_theme_*_override` and no `theme_override_*` (`theme_test.gd`): gaps come from the spacing variations (`ToyColumn…`, `ToyRow…`), and a gap the scale lacks is the empty `Control` spacer the handoff gives.
- Every player-facing text is a deck key through `tr()` (#208). Data texts (the time, player names) are set from code with `auto_translate_mode = DISABLED`.
- Sizes and offsets are px at the 1920×1080 base (#287). Slot, mic, crosshair and bar sizes are read with `get_theme_constant()` into `custom_minimum_size`, as the node lines give them (slots 88×88, the wide hand slot 180).
- Icons are the pack's white SVGs, tinted as each node line says, imported at the `svg/scale` the handoff's notes give.

## Behaviour
- Every node has `mouse_filter = IGNORE`; nothing takes focus. The HUD never shows keys, walking or running, a player list, who knocked the player down, a destination or task progress.
- Timer: the round's time left as mm:ss from code, every second. Its 140 px minimum width holds the widest time, `44:44`, so the centred plate never changes width.
- Role: the own role for the round, `role.engineer` or `role.dissident`.
- Aim: the name of the object under the crosshair within reach (`item.package`, `item.knife`, `item.switch`); hidden when nothing within reach is under it.
- Health (always shown, no numbers): `value = hp` (0 to 1); `step = clampi(floori(hp * 20.0 + 0.5), 0, 20)`, `Fill.self_modulate = get_theme_color("ramp_stop_%02d" % step, "ToyBarHealth")` (#289). Stamina (always shown): `value = stamina`; drains while sprinting, refills at rest.
- Mic: whether anyone hears the player. On: `mic.svg` tinted `icon_on`. Off (mic off, push-to-talk released, downed, pre and post game): `mic-off.svg` tinted `icon_off`.
- Slots: the hand is always the active slot. Empty shows the slot's name; a one-handed item shows only its icon (48 px); a two-handed item (the package) widens the hand slot to `wide_width` and shows its icon and its name, cut at 106 px with an ellipsis. The slot never repeats the package's room sign (#255).
- Name plates (#257): one per other player in line of sight within about 10 m. `position = camera.unproject_position(head + 0.35 m)`, the plate centred on it; hidden behind walls (raycast), beyond 10 m or behind the camera. No role, no health. The teammate mark shows only on a dissident's client and only for a teammate.
- `raising`, decided by the engineer on 2026-10-06 (#145 already shows the raise's progress to the raiser). While the player holds Interact on a downed teammate, a thin ToyBarProgress under the crosshair replaces Aim, with the same value as the downed player's raise bar; hidden on release or when the teammate is up.
