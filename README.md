# prime-game-ui

The UI and UX design track of [prime-game](https://github.com/xperiaroco2/prime-game), a first-person, low-poly,
player-hosted party game with proximity voice. This repo holds the track's research, the sources of its review pages and,
later, the design system (tokens and components) the game's Godot theme is generated from.

- **What has been decided:** [docs/ui-decisions.md](docs/ui-decisions.md)
- **Research:** [docs/research/](docs/research/)
- **Review pages:** [pages/](pages/) (published as private pages for the team)
- **Plan and reports:** [prime-game #150](https://github.com/xperiaroco2/prime-game/issues/150)
